# Module 08 — What's New

> A curated reference of every meaningful change in **EF Core 8, 9, and 10** — the features
> seniors are expected to know on sight.

The rest of the course teaches *concepts* with modern code. This module is the **release-notes
companion**: a focused tour of what each version added, in plain English, with the SQL it emits
and the gotchas it brings.

## Contents

| # | Topic | One-liner |
|---|-------|-----------|
| 01 | [EF Core 10](01.EF-Core-10.md) | **Vector data**, **SQL Server 2025 JSON type**, **LeftJoin/RightJoin**, **named filters**, ExecuteUpdate non-expression + JSON, parameterized-collection padding, Cosmos full-text |
| 02 | [EF Core 9](02.EF-Core-9.md) | Read-only primitive collections, `EF.Constant`, inlined subqueries, MSBuild compiled model, `UseAzureSql`, Cosmos rewrite, `$type` discriminator, `ToPageAsync` |
| 03 | [EF Core 8](03.EF-Core-8.md) | Complex types, primitive collections, JSON columns, **HierarchyId**, `DateOnly`/`TimeOnly`, `SqlQuery<T>`, sentinel values |
| 04 | [Version Compatibility Cheatsheet](04.Version-Compatibility-Cheatsheet.md) | LTS/STS lifecycle, .NET target matrix, upgrade tips |

## After this module you can

- Recognize and use every headline feature from EF 8 → EF 10.
- Match a feature to the version it requires.
- Plan an upgrade path that respects LTS support windows.
