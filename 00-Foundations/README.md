# Module 00 — Foundations

> What EF Core is, when to reach for it (and when not), and your first working CRUD app.

If you skip this you'll learn EF backwards: memorizing APIs without knowing what `DbContext`,
"provider," or "tracking" mean. Spend an hour here and the rest of the course clicks.

## Contents

| # | Topic | One-liner |
|---|-------|-----------|
| 01 | [What Is EF Core](01.What-Is-EF-Core.md) | The big picture: ORMs, EF vs Dapper vs raw SQL, when (not) to use EF |
| 02 | [Setting Up EF Core](02.Setting-Up-EF-Core.md) | Install (EF 10 / .NET 10), packages, project structure |
| 03 | [Your First CRUD](03.Your-First-CRUD.md) | End-to-end walkthrough: entity → migration → save/query |
| 04 | [Database Providers](04.Database-Providers.md) | SQL Server, PostgreSQL, SQLite, InMemory, Cosmos — trade-offs |

## After this module you can

- Explain what EF Core is and what it isn't.
- Set up an EF Core 10 project from scratch.
- Write a tiny CRUD app, run a migration, and query.
- Pick the right provider for a given app.
